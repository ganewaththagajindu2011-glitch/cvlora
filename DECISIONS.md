# Decisions

- Brand: CVLora. The repository name resolves the prompt's unfilled brand placeholder.
- M0 scope: create a real, runnable visual foundation and operational infrastructure. Do not simulate accounts, payments, persistence or exports. The UI labels the preview and development status explicitly.
- Fastify (MIT) is the prompt's supported backend alternative and offers a small explicit surface. Its Helmet, CORS and rate-limit plugins (MIT) enforce operational HTTP controls; ioredis (MIT) supplies Redis connectivity and distributed rate limiting.
- Next.js, React and Tailwind (MIT) are the fixed UI stack. Zod (MIT) owns strict shared validation. Prisma 6.19.3 (Apache-2.0) is pinned to a stable supported Node-24-compatible release and familiar schema workflow, with a narrow deepmerge-ts 8.0.2 override for a high-severity advisory. Prisma generation, initial migration and repeat deploy were subsequently validated after the engine domain was enabled.
- BullMQ (MIT) establishes the required worker package, but no job processor is enabled before security isolation. Its pinned 6.3.12 release is explicitly exempted from pnpm's release-age delay; package integrity and lockfile verification remain enabled.
- Fontsource font packages (OFL-1.1) self-host Inter, Outfit and Noto Sans Sinhala/Tamil. Subset Latin variable fonts are renamed CVLora Text/Display and retain original license notices. FontTools 4.61.1/Brotli 1.2.0 are optional regeneration tools, not runtime dependencies. No remote font requests. Latin UI fonts use optional display so slow connections keep the metric-adjusted fallback instead of shifting already painted content. Lighthouse budgets use the median of three runs. Script-specific fonts are included from M0; full multilingual UI/i18n belongs to M3.
- Vitest, Playwright, TypeScript, ESLint, Prettier, Husky and lint-staged provide tests and repeatable tooling. Axe-core (MPL-2.0) is used for browser accessibility tests, not linked into the shipped application. Font and tool licenses remain in installed packages.
- Use explicit TypeScript, React-hooks and JSX accessibility ESLint plugins rather than eslint-config-next: its fast-glob chain includes a high-severity braces advisory with no published patched release. Removing that unnecessary dependency chain avoids suppressing the audit. ESLint 9 is pinned for plugin compatibility; upgrade to 10 separately after compatibility validation.
- The API exposes only public operational status at M0. Private resources have no routes and return 404. There is no placeholder authorization.
- Public pages send nonce-based CSP without unsafe-inline/unsafe-eval. Next.js streaming scripts receive the request nonce. Production inline CSS is authorized only by SHA-256 hashes of trusted built stylesheets because Next.js inlineCss does not attach style nonces; unexpected injected inline styles remain blocked. Nonce rendering is dynamic; immutable static bundles/fonts can still be cached. Public sample pages contain no personal CV data; future share pages must default to noindex.
- Quality tiers consider hardware, frame rate, reduced motion/data and save-data. CSS 3D only; one small glass surface on the landing, none on scrolling cards. Low-quality devices and reduced-motion users get no hover animation.
- Locally generated secrets are development-only, not committed, printed or supplied to the draft. Future required production integrations must inspect actual bindings before requesting secure values.
- No analytics or tracking cookies are installed. Legal pages and legal review remain full-product prerequisites; this project does not claim PDPA/GDPR certification.
